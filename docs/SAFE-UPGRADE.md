# تحديث تلفزيونك مع الحفاظ على البيانات

هذه الآلية خاصة بأجهزة Android TV / Google TV التي يعمل عليها مشروع YourTV.

## ما الذي يحدث للإصدارات؟

- إذا كان **معرّف الحزمة نفسه** (`sa.urtv.screensaver` أو `sa.urtv.home`)، يستخدم التحديث `pm install -r`؛ فيستبدل النظام نسخة APK القديمة بالجديدة مع الاحتفاظ ببيانات التطبيق، ومنها المدينة والأندية ولوحة التحكم والمهام والصور.
- إذا كان الإصدار الأقدم يستخدم **معرّف حزمة مختلفًا** (`sa.yourtv.*` أو `com.abdullah.tv*`)، لا يستطيع Android نقل بياناته الخاصة إلى التطبيق الجديد تلقائيًا. لذلك يخفي المُثبّت التطبيق القديم فقط بعد نجاح تثبيت التطبيقين الجديدين؛ ولا يمسح بياناته.
- إذا كانت الشهادة التي وقّعت النسخة الحالية مختلفة عن شهادة APK الجديدة، **يتوقف التحديث دون إزالة التطبيق أو محو الإعدادات**. استخدم إصدارًا موقّعًا بالمفتاح الأصلي.

## التحديث الموصى به

على كمبيوتر متصل بالتلفزيون عبر ADB، ومن داخل المستودع:

```bash
# 1. تقرير حالة التلفزيون قبل التعديل (لا يصدّر بيانات التطبيق الخاصة)
optimize/backup.sh

# 2. عرض نسخ تلفزيونك المثبتة
bash optimize/cleanup-old-versions.sh report

# 3. تحديث التطبيقين (يتطلب APKs الرسمية الموقّعة بالمفتاح نفسه)
optimize/install.sh all
```

الأمر الأخير يستبدل التطبيقين الجديدين في مكانهما، ثم يخفي اختصارات التطبيقات القديمة ذات الأسماء الأخرى بطريقة قابلة للعكس. أعد الأمر لكل تلفزيون مستقلًا.

## قبل الحذف النهائي للأسماء القديمة

افتح لوحة التحكم، وتأكد من ظهور **المدينة، والأندية، والمفضلة، والمهام، والتذكيرات، والمناسبات، والصور** كما كانت سابقًا. إذا كانت هذه المعلومات محفوظة فقط في حزمة قديمة، لا تحذف تلك الحزمة قبل تصديرها/نقلها والتحقق من وصولها إلى الجديدة. لا يكفي ملف `optimize/backup.sh` لهذا الغرض؛ فهو تقرير بحالة النظام، وليس نسخة من بيانات التطبيقات الخاصة.

بعد **التحقق من انتقال البيانات فعليًا**، يمكنك إزالة تطبيقات الأسماء القديمة مع إبقاء بياناتها كاحتياط لاستعادتها إن لزم:

```bash
DATA_MIGRATED_AND_CHECKED=YES bash optimize/cleanup-old-versions.sh remove
```

هذه الخطوة لا تعمل تلقائيًا، لأن حماية بياناتك أهم من إخلاء مساحة بسيطة. تستخدم `pm uninstall -k --user 0` للاحتفاظ بالبيانات القديمة، ولا تحذف تطبيقًا لا يزال مُختارًا شاشةً رئيسية أو شاشة توقف.

**لا تستخدم** `pm clear` أو `pm uninstall` دون الخيار `-k` أو إعادة ضبط المصنع لإزالة الإصدارات القديمة، ولا تستخدم `optimize/reset.sh` من أجل تحديث عادي.

> ملاحظة: هذا المستودع لا يوفر اتصالًا مباشرًا من ChatGPT بأجهزة التلفزيون. يجب تشغيل الأوامر على الكمبيوتر الذي لديه صلاحية ADB، وبما أن إصدار Android الجديد لم يُنشر بعد، فهذه الخطوات للتنفيذ بعد صدور APK موقّع ومختبر.
